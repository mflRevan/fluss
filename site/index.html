00 Local dictation for Windows

Hold a key.
Speak.
It’s written.

Fluss turns your voice into text wherever your cursor is — on your own machine, in tens of milliseconds. Nothing leaves your PC.

Download for Windows Source on GitHub

01 The flow

Three motions. No window to switch to.

  2. 2Speaka live preview follows you
  3. 3Releasethe text is typed at your cursor

02 Continuation

A pause is not a full stop.

Every speech model guesses a period when you stop talking. When you keep going — after a breath in hands-free mode, or with a second press into the same text field — Fluss re-reads the last seconds of your previous audio together with the new audio, so the model itself decides how the two connect.

Only the punctuation at the seam is changed. Words already typed are never rewritten, and nothing is edited if you clicked or typed in between.

03 One-second corrections

Teach it a word without leaving the sentence.

Right after a word comes out wrong, press CtrlWinR. The popup already holds what you just said — not the last word, the last spoken chunk, found from timing, pauses, audio energy and confidence. Your cursor waits in “Should be”.

Type the spelling, press Enter. The rule is saved, the dictation you just made is corrected in place, and the word is passed to the model as a hotword from then on.

04 Pre-roll and post-roll

It hears the word you started too early.

A short ring buffer keeps the last half second before you press, and listening continues briefly after you let go. Both lengths are adjustable. If you had already stopped speaking when you released, the text is typed immediately.

06 Local by design

Small, quiet, yours.

Audio sent anywhere
0 bytes

Recognition runs on your CPU or GPU. A cloud endpoint is used only if you configure one.

Background app
~38 MB

A Rust process with a native overlay. The settings window only runs while it is open.

Installer
4 MB

Models download during setup, into a folder you can delete. No account, no telemetry.

07 Command line

Everything is scriptable.

# what Fluss is doing right now
fluss status --watch

# change any setting
fluss config set audio.preroll_ms 300

# teach it a word
fluss rules add Omarchy --heard "on march 9"

# switch engine, install, transcribe a file
fluss model use parakeet-v3 && fluss model install
fluss transcribe meeting.wav

# diagnose
fluss doctor
